# Nice Travaux Rénovation

Copie statique du site [nicetravauxrenovation.fr](https://nicetravauxrenovation.fr) (thème WordPress Avada), reconstruite en HTML/CSS pour pouvoir la modifier sans WordPress.

## Lancer

```bash
python3 -m http.server 8080
```

Puis ouvrir http://localhost:8080

## Pages

- `index.html` — accueil
- `poncage-de-parquet.html`
- `pose-de-carrelage-a-nice.html`
- `mentions-legales.html`

Les cartes de services ouvrent le calculateur déjà utilisé par le site (`ntr.calculateurtravaux.com`). Les formulaires restent dans le navigateur : ils ne sont pas reliés à une boîte mail.
